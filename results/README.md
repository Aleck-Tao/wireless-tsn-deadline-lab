# Results policy and release evidence

`release/` contains the normalized 240-run artifact generated by the GitHub Actions `full-benchmark` job after GCC, Clang, CTest, ASan/UBSan, Python validation, smoke execution, and exact provenance gates passed.

The artifact is copied without editing and retains its original `provenance.json`, complete per-run event/metadata/metric files, matrix summary, paired comparisons, and report. The source change and CI-generated evidence remain separate commits. See [`release/REPORT.md`](release/REPORT.md) for the reviewer-facing table.

The results are synthetic observations for the declared packet/slot abstraction. They are not hardware measurements, IEEE conformance evidence, or a general scheduler ranking.
